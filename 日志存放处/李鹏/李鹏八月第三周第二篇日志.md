## 一学习任务

### cv基础的代码复习

**一、安装与导入**

安装：可以使用 `pip install opencv-python` 来安装 OpenCV 的 Python 版本。

导入：import cv2

**二、读取和显示图像**

1. 读取图像：
   - 使用 `cv2.imread()` 函数读取图像。它接受图像文件的路径作为参数，并返回一个表示图像的 NumPy 数组。
   - 例如：`img = cv2.imread('image.jpg')`。
2. 显示图像：
   - 使用 `cv2.imshow()` 函数显示图像。它接受一个窗口名称和图像作为参数。
   - 例如：`cv2.imshow('Image', img)`。
   - 通常需要结合 `cv2.waitKey()` 函数来等待用户按下按键，否则窗口会立即关闭。例如：`cv2.waitKey(0)` 表示无限等待按键按下。

**三、图像基本操作**

1. 图像尺寸调整：
   - 使用 `cv2.resize()` 函数调整图像大小。它接受图像和新的尺寸（宽度和高度）作为参数。
   - 例如：`resized_img = cv2.resize(img, (new_width, new_height))`。
2. 图像裁剪：
   - 可以通过 NumPy 数组的切片操作来裁剪图像。例如，假设图像是一个三维数组（高度、宽度、通道数），可以使用 `img[start_row:end_row, start_col:end_col]` 来裁剪图像的一部分。
3. 图像颜色转换：
   - 使用 `cv2.cvtColor()` 函数进行颜色转换。例如，将彩色图像转换为灰度图像：`gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)`。

**四、图像绘制**

1. 绘制矩形：
   - 使用 `cv2.rectangle()` 函数绘制矩形。它接受图像、矩形的左上角和右下角坐标、颜色和线宽作为参数。
   - 例如：`cv2.rectangle(img, (x1, y1), (x2, y2), (0, 255, 0), 2)`。
2. 绘制圆形：
   - 使用 `cv2.circle()` 函数绘制圆形。它接受图像、圆心坐标、半径、颜色和线宽作为参数。
   - 例如：`cv2.circle(img, (x, y), radius, (255, 0, 0), 2)`。
3. 绘制线条：
   - 使用 `cv2.line()` 函数绘制线条。它接受图像、起点和终点坐标、颜色和线宽作为参数。
   - 例如：`cv2.line(img, (x1, y1), (x2, y2), (0, 0, 255), 2)`。
4. 写入文字：
   - 使用 `cv2.putText()` 函数在图像上写入文字。它接受图像、要写入的文字、文字的位置、字体类型、字体大小、颜色和线宽作为参数。
   - 例如：`cv2.putText(img, 'Hello, OpenCV!', (x, y), cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 255, 255), 2)`。

**五、图像滤波和模糊**

1. 均值滤波：
   - 使用 `cv2.blur()` 函数进行均值滤波。它接受图像和滤波器的大小作为参数。
   - 例如：`blurred_img = cv2.blur(img, (5, 5))`。
2. 高斯滤波：
   - 使用 `cv2.GaussianBlur()` 函数进行高斯滤波。它接受图像、滤波器的大小、标准差等参数。
   - 例如：`gaussian_blurred_img = cv2.GaussianBlur(img, (5, 5), 0)`。
3. 中值滤波：
   - 使用 `cv2.medianBlur()` 函数进行中值滤波。它接受图像和滤波器的大小作为参数。
   - 例如：`median_blurred_img = cv2.medianBlur(img, 5)`。

**六、边缘检测**

1. Canny 边缘检测：
   - 使用 `cv2.Canny()` 函数进行边缘检测。它接受图像、低阈值和高阈值作为参数。
   - 例如：`edges = cv2.Canny(img, 100, 200)`。

**七、视频处理**

1. 读取视频：

   - 使用 `cv2.VideoCapture()` 函数创建一个视频捕获对象，可以从摄像头或视频文件读取视频。
   - 例如，从视频文件读取：`cap = cv2.VideoCapture('video.mp4')`。

2. 逐帧处理视频：

   - 使用一个循环来逐帧读取视频，并对每一帧进行处理。可以使用 `cap.read()` 函数读取一帧视频，它返回一个布尔值表示是否成功读取帧和一个表示帧的图像。

   - 例如：

     ```python
      while True:
              ret, frame = cap.read()
              if not ret:
                  break
              # 对帧进行处理
              processed_frame = some_function(frame)
              cv2.imshow('Video', processed_frame)
              if cv2.waitKey(25) & 0xFF == ord('q'):
                  break
     ```

     

3 释放资源：

- 在处理完视频后，使用 `cap.release()` 释放视频捕获对象，并使用 `cv2.destroyAllWindows()` 关闭所有打开的窗口。
