### 2 多元特征 向量化等

**一、多类特征**

在机器学习中，特征可以分为多种类型，常见的包括：

1. **数值特征**：例如年龄、身高、体重等，可以直接用于模型计算。
2. **分类特征**：如性别（男、女）、颜色（红、绿、蓝）等，通常需要进行编码处理，例如独热编码（One-Hot Encoding）将其转换为数值形式。
3. **文本特征**：需要通过词袋模型、TF-IDF 等方法进行向量化。

**二、向量化**

向量化是将数据转换为适合计算机处理的向量形式。在多元线性回归中，假设有 `n` 个样本，每个样本有 `m` 个特征，那么数据矩阵 `X` 的维度为 `(n, m)`，目标值向量 `y` 的维度为 `(n, 1)`。

例如，对于两个样本，特征分别为 x1`[x11, x12]` 和 x2`[x21, x22]` ，则 `X = [x1, x2]` ，`y ` 。

**三、多元线性回归**

多元线性回归模型的表达式为：`y = X * θ + ε` ，其中 `y` 是目标值向量，`X` 是特征矩阵，`θ` 是参数向量，`ε` 是误差项。

**四、梯度下降法**

梯度下降法是一种用于寻找函数最小值的优化算法。在多元线性回归中，用于最小化损失函数（通常是均方误差）来求解最优的参数 `θ` 。

均方误差（MSE）损失函数：`J(θ) = 1 / (2n) * sum((y - X * θ)^2)`

梯度计算公式：`∇J(θ) = 1 / n * X^T * (X * θ - y)`

梯度下降的更新公式：`θ = θ - α * ∇J(θ)` ，其中 `α` 是学习率。

例如，假设有以下数据：

| 样本 | 特征 1 | 特征 2 | 目标值 |
| ---- | ------ | ------ | ------ |
| 1    | 2      | 3      | 7      |
| 2    | 4      | 5      | 11     |

特征矩阵 `X = [[2, 3], [4, 5]]` ，目标值向量 `y = [7, 11]` 。

初始化参数向量 `θ = [0, 0]` ，学习率 `α = 0.01` 。

第一次迭代：

```
∇J(θ) = 1 / 2 * [[2, 4], [3, 5]]^T * ([2, 4] * [0, 0] - [7, 11]) = [-10, -13]
θ = [0, 0] - 0.01 * [-10, -13] = [0.1, 0.13]
```

不断迭代，直到收敛，得到最优的参数 `θ` 。

### 3 特征缩放 等

**特征缩放**

特征缩放是将不同特征的值映射到相似的范围，常见的方法包括：

1. **标准化**：将特征值转换为均值为 0，标准差为 1 的分布。公式为：`x' = (x - μ) / σ` ，其中 `x` 是原始值，`μ` 是均值，`σ` 是标准差。

2. **归一化**：将特征值映射到 0 到 1 的区间。公式为：`x' = (x - x_min) / (x_max - x_min)` 。

3. **平均归一化**

   平均归一化是一种特征缩放的方法，其公式通常为：

   ```
   x' = (x - μ) / (x_max - x_min)
   ```

   其中：

   - `x` 是原始特征值。
   - `μ` 是特征的平均值。
   - `x_max` 是特征的最大值。
   - `x_min` 是特征的最小值。

   平均归一化的作用在于将特征值的范围映射到一个特定的区间，通常是 [-1, 1] 。

特征缩放的好处包括：

- 提高梯度下降等优化算法的收敛速度。
- 避免某些特征因数值过大或过小而对模型产生过大影响。

**检查梯度下降是否收敛**

有以下几种常见方法：

1. 绘制损失函数随迭代次数的变化曲线，如果曲线逐渐趋于平稳，说明梯度下降在收敛。
2. 比较相邻几次迭代的损失函数值，如果它们的变化很小（在某个阈值以下），则认为收敛。
3. 观察参数的变化，如果参数在后续迭代中基本不再改变，也可认为收敛。

**学习率的选择**

学习率 `α` 决定了每次参数更新的步长。

- 学习率过大可能导致损失函数无法收敛，甚至发散。
- 学习率过小会使收敛速度过慢。

常见的选择方法：

1. 手动尝试不同的固定学习率，观察模型的性能。
2. 采用自适应学习率算法，如 Adagrad、Adadelta 等。

**特征工程**

特征工程是从原始数据中提取和构建有意义的特征，以提高模型的性能。包括：

1. 特征选择：选择对目标有重要影响的特征，如相关性分析、递归特征消除等。
2. 特征构建：通过组合、变换现有特征创建新特征，例如对数值特征取对数、创建交互特征等。

**多项式回归**

多项式回归用于处理非线性关系。通过将原始特征的多项式组合作为新的特征。
例如，对于一元线性回归 `y = θ_0 + θ_1 * x` ，多项式回归可以是 `y = θ_0 + θ_1 * x + θ_2 * x^2 +... + θ_n * x^n` 。

这样可以拟合更复杂的曲线。

例如，假设我们有一组数据，其分布更接近抛物线，使用多项式回归可以更好地拟合数据。
