# 梯度上升/下降法

## 一、学习内容

  最优化问题在机器学习中有非常重要的地位，很多机器学习算法最后都归结为求解最优化问题。最优化问题是求解函数极值的问题，包括极大值和极小值。在各种最优化算法中，梯度下降法是最简单、最常见的一种方法。在深度学习的训练中被广为使用。

**梯度下降目的是找到目标函数最小化时的取值所对应的自变量的值，目的是为了找自变量X。**

#### 1.梯度下降直观理解解释

​    梯度下降法的基本思想可以类比为一个下山的过程，如下图所示函数看似为一片山林，红色的是山林的高点，蓝色的为山林的低点，蓝色的颜色越深，地理位置越低，则图中有一个低点，一个最低点。

  假设这样一个场景：一个人被困在山上（图中红圈的位置），需要从山上下来(找到山的最低点，也就是山谷)，但此时山上的浓雾很大，导致可视度很低。因此，下山的路径就无法确定，他必须利用自己周围的信息去找到下山的路径。这个时候，他就可以利用梯度下降算法来帮助自己下山。具体来说就是，以他当前的所处的位置为基准，寻找这个位置最陡峭的地方，然后朝着山的高度下降的方向走，然后每走一段距离，都反复采用同一个方法，最后就能成功的抵达山谷。

## 个人理解：

梯度下降法旨在小步长（学习率）下多次计算最优方向（梯度），最终找到最低点

其中最重要的就是学习率的设置，防止找到的是鞍点，当然随机下降法规避了这种风险。

代码：

```python
def gradient_descent(gradient, start_point, learning_rate, iterations, tolerance=1e-6):
    """
    梯度下降法

    :param gradient: 梯度函数，接受一个点的参数值并返回该点的梯度
    :param start_point: 初始参数值
    :param learning_rate: 学习率
    :param iterations: 迭代次数
    :param tolerance: 容差，用于判断是否收敛
    :return: 最小值点和对应的函数值
    """
    point = start_point
    for i in range(iterations):
        grad = gradient(point)
        if abs(grad) < tolerance:
            return point, func(point)  # 假设func是你要最小化的函数
        point -= learning_rate * grad
    return point, func(point)

# 示例：最小化函数 f(x) = (x-2)^2
def func(x):
    return (x - 2) ** 2

def gradient_of_func(x):
    return 2 * (x - 2)

# 初始参数值，学习率，迭代次数
start_x = 0
learning_rate = 0.1
iterations = 100

# 执行梯度下降
optimal_x, optimal_value = gradient_descent(gradient_of_func, start_x, learning_rate, iterations)
print(f"Optimal x: {optimal_x}, Optimal value: {optimal_value}")
```
