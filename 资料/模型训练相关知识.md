#### 收敛

打个简单的比方，训练网络模型，就好比解方程，为了得到这个方程的极值点，训练的过程就好比是找准一个方向，不断的朝这个方向靠近,使得方程的值不断减小，最终达到极值点，而不收敛，就是，不论你怎么跑，方程的解都不减小。

#### 梯度下降：[机器学习-梯度下降算法原理及公式推导_梯度下降计算公式-CSDN博客](https://blog.csdn.net/iqdutao/article/details/107174240)

#### 超参数调优：

##### 初级

​        **学习率调整**：改变学习率的大小，如使用学习率调度器或自适应学习率优化器（如Adam）。

​        **批量大小**：调整每次迭代处理的数据样本数量。

##### 高级

​        **优化器选择**：尝试不同的优化算法，如SGD、Adam、RMSprop等。

​        **网络结构**：修改网络层数、每层的神经元数量等。

​        **正则化方法**：应用dropout、L2正则化等来防止过拟合。

​        **激活函数**：实验不同的激活函数，如ReLU、Sigmoid、Tanh等



## 上手操作

更改生效

```
python setup.py develop
```

训练命令：

```
python tools/train.py -f exps/example/yolox_voc/yolox_voc_s.py -d 0 -b 4 --fp16  -c yolox_s.pth
```

推理命令：

```
python tools/demo.py image -f exps/example/yolox_voc/yolox_voc_s.py -c weights/best_ckpt.pth --path assets/class01.jpg --conf 0.25 --nms 0.45 --tsize 640 --save_result --device [cpu/gpu]
```
